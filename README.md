# SplitEase

> Split expenses with friends, simplify who owes whom, and settle up with one-tap UPI.

## Features
- JWT auth, groups, equal/custom expense splits
- Balances + simplify-debts (fewest payments)
- UPI deep-link settle-up
- Natural-language expense entry (AI draft, user confirms)

## Technologies Used
MongoDB, Express.js, React, Node.js, Mongoose, JWT, Tailwind CSS, Gemini API

## Setup and Installation
```bash
git clone <repo-url> && cd splitease
cd server && npm install && cp .env.example .env   # fill MONGO_URI and JWT_SECRET
# GEMINI_API_KEY is optional: without it, natural-language entry uses a rule-based parser
cd ../client && npm install
cd server && npm run seed      # optional: seed the database with sample data
```

## How to Run
```bash
cd server && npm run dev     # API on :5000
cd client && npm run dev     # UI on :5173
cd server && npm test        # unit tests
cd server && npm run seed     # seed sample data into the database
```

## Deployment

The API is hosted on [Render](https://render.com) and the client on [Vercel](https://vercel.com).

### API — Render

1. Create a new **Web Service** on Render and connect this repository.
2. Set **Root Directory** to `server`, **Build Command** to `npm install`, and **Start Command** to `npm start`.
3. Render uses `render.yaml` at the repo root to pre-fill these settings; you can also import the repo via **Blueprint** to apply it automatically.
4. In the Render dashboard, add each environment variable listed in the table below under **Environment → Add Environment Variable**.
5. After the first deploy, copy the service URL (e.g. `https://splitease-api.onrender.com`) for the next step.

### Client — Vercel

1. Import the repository on [Vercel](https://vercel.com/new).
2. Set **Root Directory** to `client`. Vercel detects Vite automatically.
3. Under **Environment Variables**, add `VITE_API_URL` pointing to your Render service URL with the `/api` suffix (e.g. `https://splitease-api.onrender.com/api`).
4. Deploy. `client/vercel.json` handles the SPA rewrite so React Router routes work on hard refresh.

### Environment variables

| Variable | Service | How to set | Description |
|---|---|---|---|
| `MONGO_URI` | Render | Dashboard → Environment | MongoDB Atlas connection string |
| `JWT_SECRET` | Render | Auto-generated by `render.yaml` | Token signing secret — Render creates a random value |
| `CLIENT_URL` | Render | Dashboard → Environment | Vercel deployment URL, e.g. `https://splitease.vercel.app` (used for CORS) |
| `GEMINI_API_KEY` | Render | Dashboard → Environment | Google Gemini key; leave blank to fall back to rule-based parsing |
| `GEMINI_MODEL` | Render | Dashboard → Environment | Gemini model name, e.g. `gemini-1.5-flash` (optional) |
| `VITE_API_URL` | Vercel | Dashboard → Environment Variables | Full API URL including `/api`, e.g. `https://splitease-api.onrender.com/api` |

> **Warning — `VITE_` variables are public.** Vite inlines any variable prefixed `VITE_` into the compiled JavaScript bundle, which is served to every visitor. Never put secrets (API keys, tokens) in a `VITE_` variable.
